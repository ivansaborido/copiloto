Conecta tu Microsoft 365

Introduce el ID de aplicación que crearás en Azure (3 minutos, gratis). La app inicia sesión como tú y solo hace lo que tú ya puedes hacer con tu correo.

Deja organizations o pega el ID de directorio de tu empresa si lo tienes.
¿Cómo consigo el ID de aplicación?
  1. Entra en entra.microsoft.com con tu cuenta de la empresa → Aplicaciones → Registros de aplicaciones → Nuevo registro.
  2. Nombre: Copiloto de Voz. En Tipos de cuenta admitidos elige “Solo este directorio organizativo”.
  3. En URI de redirección elige la plataforma SPA (aplicación de página única) y pega exactamente esta dirección (la de donde alojas esta app):
  4. Registra. Copia el ID de aplicación (cliente) y pégalo arriba. Copia también el ID de directorio (inquilino) para el campo Organización.
  5. En Permisos de API → Agregar permiso → Microsoft Graph → Permisos delegados, añade: User.Read, Mail.Read, Mail.ReadWrite, Mail.Send.
Si al iniciar sesión te aparece “necesitas aprobación del administrador”, tu empresa exige que IT autorice la app. En ese caso este atajo no aplica y habría que pedírselo a IT.
